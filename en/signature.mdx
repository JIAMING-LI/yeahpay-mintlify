Generate a new signature for every request. The signature covers the request path, common parameters, raw request body, and `apiKey`.

## Signing text

Join the following fields in this exact order. Insert one ASCII line feed `\n` (`0x0A`) between fields. Do not append a line feed after the final field.

```text
signUrl
appId
timestamp
version
nonce
rawBody
apiKey
```

Calculate the signature as follows:

```text
signature = Base64(SHA-512(UTF-8(signText)))
```

<Warning>
  `rawBody` must be the exact JSON string sent in the request. Do not serialize it again, format it, reorder fields, or change whitespace after signing.
</Warning>

## Signing URL

Use the actual request path without the protocol, hostname, query string, or transport gateway prefix.

```text
Sandbox request:
https://open-api.yeahpay.net/acceptance/sandbox/consent-payment/customers/query

Signing URL:
/sandbox/consent-payment/customers/query

Production PaymentIntent request:
https://open-api.yeahpay.net/gwp/checkout/openapi/v2/createIntent

Signing URL:
/checkout/openapi/v2/createIntent
```

Remove the leading gateway segment `/acceptance` or `/gwp` once and retain the rest. For sandbox PaymentIntent requests, `/acceptance/sandbox/openapi/v2/createIntent` becomes `/sandbox/openapi/v2/createIntent`. Select the environment in the [signed request tester](/en/api-tester) to obtain the matching path.

## Generate and send a request

<Steps>
  <Step title="Freeze the raw request body">
    Serialize the business object to compact JSON once and save it as `rawBody`.
  </Step>
  <Step title="Prepare the common parameters">
    Generate a 13-digit millisecond `timestamp` and a unique `nonce`. Use `1.0` for `version`.
  </Step>
  <Step title="Build the signing text">
    Join the seven fields in the required order with `\n`.
  </Step>
  <Step title="Calculate and send">
    Calculate the SHA-512 digest, encode it with standard Base64, and put the result in the `signature` header. Send the saved `rawBody` without changing it.
  </Step>
</Steps>

## Code examples

<Tabs>
  <Tab title="JavaScript">
    ```javascript
    import { createHash, randomUUID } from "node:crypto";

    const baseUrl =
      "https://open-api.yeahpay.net";
    const path = "/acceptance/sandbox/consent-payment/customers/query";
    const appId = process.env.YEAHPAY_APP_ID;
    const apiKey = process.env.YEAHPAY_API_KEY;
    const version = "1.0";
    const timestamp = Date.now().toString();
    const nonce = randomUUID().replaceAll("-", "");

    const body = {
      merchantId: "YOUR_MERCHANT_ID",
      merchantCustomerId: "YOUR_CUSTOMER_REFERENCE",
    };

    // Serialize once. Signing and sending must use the same string.
    const rawBody = JSON.stringify(body);

    function buildSignUrl(requestBaseUrl, requestPath) {
      const basePath = new URL(`${requestBaseUrl.replace(/\/+$/, "")}/${requestPath.replace(/^\/+/, "")}`).pathname
        .replace(/^\/(?:gw|gwp|acceptance)(?=\/)/, "")
        .replace(/\/+$/, "");
      return basePath;
    }

    const signUrl = buildSignUrl(baseUrl, path);
    const signText = [
      signUrl,
      appId,
      timestamp,
      version,
      nonce,
      rawBody,
      apiKey,
    ].join("\n");

    const signature = createHash("sha512")
      .update(signText, "utf8")
      .digest("base64");

    const response = await fetch(`${baseUrl}${path}`, {
      method: "POST",
      headers: {
        "Content-Type": "application/json",
        "Accept-Language": "en",
        "Accept-Timezone": "Asia/Singapore",
        appId,
        version,
        timestamp,
        nonce,
        algorithm: "SHA-512",
        signature,
      },
      body: rawBody,
    });

    console.log(response.status, await response.text());
    ```

    ```java
    import java.net.URI;
    import java.net.http.HttpClient;
    import java.net.http.HttpRequest;
    import java.net.http.HttpResponse;
    import java.nio.charset.StandardCharsets;
    import java.security.MessageDigest;
    import java.time.Instant;
    import java.util.Base64;
    import java.util.UUID;

    String baseUrl =
        "https://open-api.yeahpay.net";
    String path = "/acceptance/sandbox/consent-payment/customers/query";
    String appId = System.getenv("YEAHPAY_APP_ID");
    String apiKey = System.getenv("YEAHPAY_API_KEY");
    String version = "1.0";
    String timestamp = String.valueOf(Instant.now().toEpochMilli());
    String nonce = UUID.randomUUID().toString().replace("-", "");

    // Signing and sending must use exactly the same rawBody.
    String rawBody = """
        {"merchantId":"YOUR_MERCHANT_ID","merchantCustomerId":"YOUR_CUSTOMER_REFERENCE"}
        """.strip();

    String basePath = URI.create(baseUrl.replaceAll("/+$", "") + path).getPath();
    if (basePath.startsWith("/gw/")) {
        basePath = basePath.substring("/gw".length());
    } else if (basePath.startsWith("/gwp/")) {
        basePath = basePath.substring("/gwp".length());
    } else if (basePath.startsWith("/acceptance/")) {
        basePath = basePath.substring("/acceptance".length());
    }
    String signUrl = basePath.replaceAll("/+$", "");

    String signText = String.join(
        "\n", signUrl, appId, timestamp, version, nonce, rawBody, apiKey);
    byte[] digest = MessageDigest.getInstance("SHA-512")
        .digest(signText.getBytes(StandardCharsets.UTF_8));
    String signature = Base64.getEncoder().encodeToString(digest);

    HttpRequest request = HttpRequest.newBuilder(
            URI.create(baseUrl.replaceAll("/+$", "") + path))
        .header("Content-Type", "application/json")
        .header("Accept-Language", "en")
        .header("Accept-Timezone", "Asia/Singapore")
        .header("appId", appId)
        .header("version", version)
        .header("timestamp", timestamp)
        .header("nonce", nonce)
        .header("algorithm", "SHA-512")
        .header("signature", signature)
        .POST(HttpRequest.BodyPublishers.ofString(rawBody, StandardCharsets.UTF_8))
        .build();

    HttpResponse<String> response = HttpClient.newHttpClient().send(
        request, HttpResponse.BodyHandlers.ofString(StandardCharsets.UTF_8));
    System.out.println(response.statusCode() + " " + response.body());
    ```

## Verify notification signatures

Payment result, refund result, and payment link paid notifications from YeahPay are plain JSON with no additional encryption, so you only need to verify the signature. Verification uses the same signing-text order and algorithm as outgoing requests, with these differences:

| Field | Outgoing request | Notification verification |
| --- | --- | --- |
| `signUrl` | Request path without the gateway prefix | The complete callback URL you configured, including protocol, hostname, path, and query string |
| `appId`, `timestamp`, `version`, `nonce` | Generated by you and sent as headers | Read the original values from the notification headers |
| `rawBody` | The raw body you send | The raw body you receive |
| `apiKey` | Your `apiKey` | The same `apiKey` |

<Steps>
  <Step title="Keep the raw body">
    Before parsing JSON, save the received body as a UTF-8 string `rawBody`. When using a framework, receive the body as a string (for example `@RequestBody String` in Spring) instead of binding it to an object and serializing it again.
  </Step>
  <Step title="Read the notification headers">
    Read `appId`, `timestamp`, `version`, `nonce`, and `signature`. HTTP header names are case-insensitive; payment link notifications use `appid`.
  </Step>
  <Step title="Calculate and compare the signature">
    Use the notification URL exactly as you supplied it when creating the order or link as `signUrl`; do not rebuild it from the incoming Host or proxy headers. Calculate `Base64(SHA-512(UTF-8(signText)))` in the signing-text order and compare it with the `signature` header in constant time.
  </Step>
  <Step title="Process and respond">
    Parse the JSON only after verification succeeds, process it idempotently by order number, and return plain-text `success`. If verification fails, do not return `success` or update the order.
  </Step>
</Steps>

<Tabs>
  <Tab title="JavaScript">
    ```javascript
    import { createHash, timingSafeEqual } from "node:crypto";
    import { createServer } from "node:http";

    const apiKey = process.env.YEAHPAY_API_KEY;
    // Must match the notification URL sent with the order, including the query string.
    const callbackUrl = "https://shop.example.com/payment/notify";

    function verifyNotification(headers, rawBody) {
      // Node.js lowercases header names.
      const signText = [
        callbackUrl,
        headers.appid,
        headers.timestamp,
        headers.version,
        headers.nonce,
        rawBody,
        apiKey,
      ].join("\n");
      const expected = createHash("sha512").update(signText, "utf8").digest();
      const received = Buffer.from(headers.signature ?? "", "base64");
      return received.length === expected.length && timingSafeEqual(received, expected);
    }

    createServer((req, res) => {
      const chunks = [];
      req.on("data", chunk => chunks.push(chunk));
      req.on("end", () => {
        const rawBody = Buffer.concat(chunks).toString("utf8");
        if (!verifyNotification(req.headers, rawBody)) {
          res.writeHead(401).end();
          return;
        }
        const notification = JSON.parse(rawBody);
        // Process idempotently by notification.thirdOrderId.
        res.writeHead(200, { "Content-Type": "text/plain" }).end("success");
      });
    }).listen(8080);
    ```
  </Tab>
  <Tab title="Java">
    ```java
    import java.nio.charset.StandardCharsets;
    import java.security.MessageDigest;
    import java.util.Base64;

    public final class YeahPayNotificationVerifier {

        // Must match the notification URL sent with the order, including the query string.
        private static final String CALLBACK_URL = "https://shop.example.com/payment/notify";

        public static boolean verify(String appId, String timestamp, String version, String nonce,
                                     String signature, String rawBody, String apiKey) throws Exception {
            String signText = String.join(
                "\n", CALLBACK_URL, appId, timestamp, version, nonce, rawBody, apiKey);
            byte[] expected = MessageDigest.getInstance("SHA-512")
                .digest(signText.getBytes(StandardCharsets.UTF_8));
            byte[] received = Base64.getDecoder().decode(signature);
            // Constant-time comparison.
            return MessageDigest.isEqual(expected, received);
        }
    }
    ```

## Common signature errors

| Problem | Resolution |
| --- | --- |
| Signing the complete request URL | Use only the YeahPay verification path without the protocol or hostname |
| Including `/gw` or `/acceptance` in the signing URL | Remove the transport gateway prefix |
| Serializing JSON again after signing | Save and reuse the same `rawBody` |
| Using a timestamp in seconds | Use a 13-digit timestamp in milliseconds |
| Using a hexadecimal SHA-512 digest | Use standard Base64 encoding |
| Sending `apiKey` in a request header | Use `apiKey` only when calculating the signature |
| Verifying a notification with the gateway-stripped path | Use the complete callback URL for notifications |
| Verifying a notification after parsing and re-serializing JSON | Verify with the raw body you received |
